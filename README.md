# CampusExist

You are my senior full-stack developer and technical mentor. Help me build CampusExist for AURIX Hackathon 2026 at IILM University, Greater Noida.

I am a beginner, so make the project reliable, maintainable and easy for me to explain to judges.

PROJECT GOAL:
CampusExist is a student campus utility platform for listing, borrowing, renting, buying and selling college essentials, reporting lost and found belongings, tracking borrowing requests, and privately managing personal belongings.

TECHNICAL REQUIREMENTS:
- Build a responsive web application using a suitable modern frontend framework supported by this builder.
- Use TypeScript if supported by the generated stack.
- Use Supabase for the backend, database and authentication.
- Prepare the application for deployment and GitHub version control.
- Use reusable components and clear project structure.
- Do not create a separate native Android or iOS application.
- Do not claim that a feature is working until it has been implemented and tested.

PAGES:
1. Home dashboard
2. Marketplace
3. Lost & Found
4. Borrowing Requests
5. My Belongings
6. Sign In and Sign Up
7. User Profile
8. A simple help and safety page

DESIGN:
- Professional, modern, trustworthy and student-friendly.
- Mobile-first responsive layout.
- Consistent typography, spacing, colors and icons.
- Clear navigation and accessible forms.
- Attractive item cards, search bars, filters and status indicators.
- Avoid excessive animations and unnecessary decorative elements.

IMPORTANT:
First inspect the project requirements and propose the architecture, page structure, database needs and implementation order. Then build the initial frontend and navigation.

Do not build fake backend functionality. Clearly distinguish features that are complete from features that still require database integration. Do not add unnecessary AI chatbots, payment gateways or complex features.
